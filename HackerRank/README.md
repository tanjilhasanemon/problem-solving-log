# HackerRank

Solutions and notes for HackerRank problems.

## Structure

```text
HackerRank/
|-- Arrays/
|-- Strings/
|-- Linked List/
|-- Trees/
|-- Dynamic Programming/
|-- README.md
```

## How To Use

1. Put each solution in the closest topic folder.
2. Use readable file names based on problem title.
3. Keep one approach per file unless comparing methods.
4. Update root tracker and monthly changelog after solving.
